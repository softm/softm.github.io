내 기록은 어디에 저장되나요?

현재는 이 브라우저의 IndexedDB

집 정보·체크리스트·메모·첨부 파일은 사용하는 브라우저의 사이트 저장소에 보관합니다. 이 앱은 해당 내용을 서버로 전송하지 않습니다. 소셜 로그인, 사용자별 서버 보관, 기기 간 동기화는 아직 연결하지 않았습니다.

같은 기기·브라우저·사이트 주소로 다시 방문하면 기록을 읽을 수 있습니다. 시크릿 모드 종료, 사이트 데이터 삭제, 저장 공간 회수, 브라우저 변경 시 기록이 사라질 수 있습니다. 앱의 백업 기능을 이용하세요.

개인 자료 보관 시 주의

이 버전의 로컬 데이터와 JSON 백업은 앱 자체 암호화가 적용되지 않습니다. 공용 PC에 민감 서류를 올리지 마세요. 같은 웹 출처의 다른 앱이나 브라우저 확장 프로그램 등도 보안 경계에 영향을 줄 수 있습니다. 계약서에는 꼭 필요한 정보만 남기고 주민등록번호·계좌번호·신분증 등은 가린 사본을 사용하세요.

GitHub Pages는 공개 웹앱 파일을 제공하는 호스팅이며, 사용자별 비공개 문서 서버가 아닙니다. 사용자가 등록한 문서를 GitHub 저장소나 배포 파일에 포함하지 않습니다. 외부 공식 사이트로 이동하면 해당 사이트의 정책이 적용됩니다.

백업·복원·삭제

백업 저장 시 기록만 또는 원본 서류 포함을 선택할 수 있습니다. 백업 파일에는 개인정보가 들어갈 수 있으므로 안전한 개인 공간에 보관하세요. 가져오기는 기존 기록을 덮어쓰지 않고 새 프로젝트를 만듭니다. 현재 복원 범위와 한계는 가져오기 확인 화면에 표시합니다.

프로젝트의 집 정보 수정 화면에서 프로젝트와 연결된 파일을 삭제할 수 있습니다. 서류 개별 삭제 시 연결된 점검 상태는 미확인으로 바뀝니다. 이미 내려받은 백업·원본 파일은 기기에서 별도로 삭제해야 합니다.
