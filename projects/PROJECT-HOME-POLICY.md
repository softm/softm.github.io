# 프로젝트 홈과 채팅 접근 규칙

적용일: 2026-09-30. 이 문서의 탐색 규칙은 이전 문서의 모호한 홈 연결·이중 인증 표현보다 우선합니다.

전체 프로젝트 → 공개 GitHub Pages 프로젝트 홈 → 공개·비공개 채팅 목록 → 선택한 원문.

- 프로젝트명과 프로젝트 홈 버튼은 `https://softm.github.io/projects/<project>/`로 연결합니다. GitHub 저장소 화면이나 비공개 홈으로 대체하지 않습니다.
- 모든 프로젝트 홈은 로그인 없이 읽는 공개 목차입니다. 공개·비공개 채팅 목록을 각각 표시하며, 없는 목록은 미등록으로 표시합니다.
- 공개 저장소와 비공개 저장소 링크를 함께 표시합니다. 존재하지 않는 저장소 링크는 표시하지 않습니다.
- 홈에는 안전한 제목·목록·접근 링크만 표시합니다. 비공개 본문·이미지·영상·음성·문서는 해당 원본 저장소와 인증 서버에 유지합니다.
- 비공개 항목은 루트 홈이 아닌 개별 채팅의 원문 주소로 연결합니다. 해당 서버의 비밀번호 또는 활성화된 Vercel 인증을 통과한 후 원래 선택한 경로로 돌아가야 합니다.
- 같은 URL에 인증 버튼 이름만 다르게 붙이지 않습니다. Vercel 계정 선택 인증은 실제 활성화·동작을 검증하기 전에는 구현 완료로 표시하지 않습니다. 선택형 인증 요청을 필수 이중 인증으로 바꾸지 않습니다.
- `projects.json`의 기존 상세 링크와 자산 메타데이터는 그대로 보존하고 `project-home.js`가 프로젝트 홈 주소 및 안전한 추가 채팅 목록을 결합합니다. 기존 상세 정리를 새 요약문으로 바꾸지 않습니다.
- GitHub Pages 운영 반영, 인증 후 원문 열람, 실제 미디어 표시는 별도 검증 대상입니다.

등록된 프로젝트 홈: 화곡농장, 광명, 나, 온수힐, 연서, 웅도, 화곡리 개간허가, 아버지 병원 치료, 돌봄한눈, 메디찾기, 경주김씨, 서해박속낙지, 가족여행.
