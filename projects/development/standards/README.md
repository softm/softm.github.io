# 공통 개발 기준

이 디렉토리는 여러 GitHub 저장소에서 재사용하는 공통 개발·운영 기준의 중앙 저장소다.

## 디렉토리
- `map/` — 지도 UX, 지도 집중모드, 마커/팝업, 위치 기능
- `data/` — 데이터 수집, 갱신, 상태 표시
- `naming/` — 서비스/저장소/화면 명명
- 상위 `../workflows/` — 공통 작업 절차
- 상위 `../templates/` — 공통 프롬프트/템플릿

## 원칙
1. 여러 저장소에 반복 적용되는 규칙은 여기에서 원본을 관리한다.
2. 개별 저장소 문서는 이 기준을 링크하거나 서비스별 차이만 기록한다.
3. 기준 변경 시 날짜와 변경 이유를 남긴다.
4. 실제 구현과 기준 문서가 다르면 구현을 점검하고 기준을 최신화한다.
