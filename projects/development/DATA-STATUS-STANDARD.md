# 데이터 수집 현황 공통 개발 기준

확정일: 2026-10-20 (한국 시간)

사용자 확정 지시: **데이터를 수집하는 프로젝트는 `data-status.html`을 반드시 구현해 실제 수집 결과를 표시한다.** 이 기준은 충전한눈에 한정하지 않고 앞으로 작업하는 모든 데이터 수집형 앱·사이트에 적용한다. 기존 프로젝트의 일괄 수정·배포가 완료됐다는 의미는 아니며, 각 프로젝트에서 실제 적용·검증한 범위를 별도로 보고한다.

| 항목 | 필수 동작 |
| --- | --- |
| 고정 진입점 | 운영 루트의 `data-status.html`. 메인 화면에 ‘수집 현황’ 링크 제공 |
| 실제 수집 결과 | 배포에 쓰이는 manifest 또는 안전한 집계 API에서 자동으로 읽음. 숫자·성공 상태를 수동으로 고정하지 않음 |
| 전체 및 구간별 집계 | 총 건수와 출처·지역·카테고리 등 데이터 분할별 건수 표시. 합계 불일치 구분 |
| 시각 | 마지막 정상 수집·결과 생성·상태 확인·페이지 확인 시각을 구분하고 시간대 표시 |
| 상태 | 수집 완료·미수집·오류·부분 수집·갱신 지연 구분. 정상 이전 자료를 보여주는 경우 명시 |
| 용량 및 형식 | JSON/JSON.gz 등의 실제 형식, 원본·전송 용량, 압축 절감량을 확인 가능한 범위에서 표시. 미확인 수치는 미확인으로 표시 |
| 파일 검사 | 실제 게시 파일의 접근·해제·스키마·건수를 대조할 수 있는 검사 또는 배포 검증 제공. 요약 파일을 읽은 것을 전체 파일 검증 완료로 표시하지 않음 |
| 갱신 설정 | 예약 수집 활성 여부와 알려진 주기를 표시. 페이지 새로고침과 원본 데이터 재수집을 구분 |
| 출처 | 공개 가능한 공식 출처 및 데이터 설명 연결 |
| 개인정보·인증 | 서비스키·토큰·개인 원문·비공개 요청 URL·원본 오류 응답을 노출하지 않음. 비공개 데이터의 현황은 기존 인증 범위 유지 |
| 가벼운 기본 조회 | 기본 화면은 집계 메타데이터만 읽고, 대용량 지역 파일은 필요 시 검사. 모바일에 가로 넘침 없이 표시 |
| 배포 완료 조건 | 현황 페이지와 메인 진입 링크 HTTP 200, 스크립트·스타일 정상, 실제 결과와 합계 대조. 수집 성공·배포 성공·현황 조회 성공을 각각 검증 |

적용 시 각 프로젝트의 `AGENTS.md` 또는 개발 지침에서 이 문서를 연결하고, 자동 배포 검증에 페이지 누락 검사를 포함한다. 데이터나 운영 설정을 알 수 없으면 추정한 성공 상태로 대체하지 않는다.

첫 적용: [충전한눈 구현 저장소](https://github.com/softm/evchargingstation) · [운영 수집 현황](https://softm.github.io/evchargingstation/data-status.html).
