# 자료 정리·아카이브 생성 공통 기준

최종 갱신: 2026-10-09

이 문서는 채팅/업로드 자료의 **정리 단계**부터 MD·HTML·ZIP 생성과 공개/비공개 배포까지 공통으로 적용한다. 상세 배포 운영 규칙은 [중앙 실행 기준](MD-HTML-ZIP-PROMPT.md), 뷰어 포맷은 [미디어 뷰어 정책](MEDIA-VIEWER-POLICY.md)을 따른다.

## 1. 수집·범위
- 사용자가 범위를 지정하면 그 범위를 우선한다. 별도 지정이 없고 '채팅 전체 정리' 요청이면 접근 가능한 현재 대화 및 실제 첨부 원본을 포함한다.
- 이미지·영상·음성·PDF·텍스트·문서 등 원본을 보존한다. 접근할 수 없는 파일은 임의 생성하지 않고 누락을 표시한다.
- 제품명·일자·수치·확인된 사실과 추정/미확인 사항을 구분한다. 농약 등 안전 정보는 등록 작물·라벨 확인 없이 사용 가능하다고 확정하지 않는다.

## 2. 정리 형식
- 제목, 작성일, 요약, 표, 상세 설명, 출처/첨부, 주의사항 순으로 구조화한다.
- 이미지가 여러 장이면 작고 균일한 썸네일로 표시하고, 같은 제품/주제의 이미지는 같은 행에 묶는다.
- MD와 반응형 HTML을 생성하고 이미지·미디어 원본을 상대 경로로 연결한다. ZIP 안에 모두 포함해 오프라인에서도 열리게 한다.

## 3. 미디어 통합 뷰어
- 썸네일/파일 항목 클릭 시 레이어 뷰어를 연다. 이미지·동영상·오디오·PDF 및 가능한 문서를 형식별 뷰어/플레이어로 표시한다.
- 동일 아카이브의 탐색 가능 항목을 정렬 순서대로 **이전/다음**으로 이동한다.
- 이전/다음 버튼, 현재 순번/총 개수, 닫기, 파일명, 원본 열기/다운로드를 제공한다.
- 가능한 경우 키보드 ←/→, ESC, 모바일 스와이프, 이미지 확대/축소, 동영상/음성 재생 컨트롤을 제공한다.
- 미디어 전환 시 기존 영상·음성을 정지한다. 지원하지 않는 코덱은 안내 및 원본 다운로드를 제공한다.
- 비공개 파일을 외부 공개 뷰어로 전송하지 않고 인증·권한을 유지한다.

## 4. 배포·검증
- 공개/비공개 분리, 프로젝트 홈과 전체 프로젝트 인덱스 연결, 제목/폴더명 일치, 인증 후 원래 상세 경로 복귀를 점검한다.
- MD만, 텍스트만, 미디어만 있어도 열람 가능한 HTML 목록/뷰어를 생성한다.
- ZIP 내부 상대경로, 미디어 누락, 404, 링크, 뷰어 첫/끝 항목, 키보드/모바일, 미디어 재생, 권한 차단을 검증한다.
- 배포 완료는 실제 푸시·배포·접속 확인 이후에만 선언한다. ZIP 삭제 등 정리 작업도 검증 이후 실행한다.
- 완료 보고에 프로젝트명, 저장소 링크, 운영 URL, 복사 가능한 URL, 검증 결과, 미완료 항목을 포함한다.

## 5. 적용 범위
이후 모든 '정리', 'md/html to zip', '아카이브 배포', 공개·비공개 배포에 기본 적용한다. 기존 산출물은 실제 재생성·재배포 전까지 소급 완료로 간주하지 않는다.
