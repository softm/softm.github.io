## 3. 구체화한 운영 형식과 과거 요구의 구분

`source-inventory.csv`, `verification-report.md`, 세부 manifest 필드, cleanup 직전 해시 재확인 등은 원본 누락 방지·무결성·정직한 완료 보고 요구를 실행 가능하게 정리한 형식이다. 각각의 파일명이나 필드명이 과거 사용자의 문자 그대로의 지시였다고 주장하지 않는다.

이번 프롬프트·기준 등록은 개별 비공개 기록 공개, 기존 기록 삭제, 전체 프로젝트 재배포 또는 인증 설정 변경을 지시하지 않는다. 실제 배포 요청 시 필요한 절차를 규정한다.
