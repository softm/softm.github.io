# 아카이브 배포 통합 프롬프트

최종 갱신: 2026-10-07 · 기준 버전: 2026-10-07.1

## 실행 기준

`정리 md, html to zip`, `현재 채팅 전체 md, html to zip`, `정리 md, html to zip(모든 이미지 포함)` 실행 시 [MD · HTML · ZIP 통합 실행 프롬프트](MD-HTML-ZIP-PROMPT.md)를 읽고 그 기준으로 수행한다.

자료 확인 → 현재 채팅 전체 기록 재구성 → 사건일·제목·id/slug 확정 → 모든 확보 원본을 포함한 MD·HTML·ZIP 생성 → 파일·해시·내용·상대경로 검증 → 기존 공개/비공개 저장소·배포 연계 → 프로젝트 자체 홈·중앙 프로젝트 홈·전체 projects 동기화 → 인증·운영 상세·미디어 검증 → 링크와 상태를 갖춘 완료 보고까지 포함한다.

기준·프롬프트 작성 요청은 그 자체로 개인 기록 공개나 전체 프로젝트 재배포 요청이 아니다. 현재 요청의 범위 제한을 우선한다.

## 최신 핵심 예외

| 상황 | 처리 |
|---|---|
| 정상 원본 HTML 있음 | HTML 우선 보존. MD로 임의 재생성하지 않음 |
| HTML 없이 MD/TXT 있음 | 원문 전체를 읽기용 HTML로 렌더링 |
| 미디어·문서만 있음 | 갤러리·플레이어·열기·다운로드를 갖춘 HTML 생성 |
| Markdown 덤프형 HTML | 원본 보존 후 정상 HTML 정규화 |
| 원본 미확보 | 누락을 명시. 가짜 자료로 대체하거나 완전본이라고 보고하지 않음 |
| 비공개 원본 | Private GitHub 단일 원본 + 인증된 Vercel live-read gateway |
| 검증 미완료 | 성공한 단계만 보고. 수집함 원본 유지 |

충돌 시 최신 사용자 확정 기준과 통합 실행 프롬프트를 우선하고, 충돌하지 않는 기존 기준은 유지한다. 공통 기준 문서에 개인 민감 원문을 넣지 않는다.

## 2026-10-07 확정: 가능한 모든 형식 뷰어·플레이어

[미디어·문서 뷰어/플레이어 기준](MEDIA-VIEWER-POLICY.md)을 공통 필수 기준으로 적용한다. 텍스트·MD·이미지·영상·음성·PDF·DOCX·스프레드시트·구조화 문서·ZIP은 가능한 인라인 뷰어를 제공한다. 미지원 형식/코덱은 한계를 명시하고 원본 열기·다운로드를 유지한다. 비공개 원문을 외부 뷰어로 보내지 않는다. 현재 요청의 실제 적용 대상은 온수힐이며, 다른 프로젝트까지 배포 완료됐다고 보고하지 않는다.
