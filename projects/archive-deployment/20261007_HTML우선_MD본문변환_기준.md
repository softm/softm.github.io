# HTML 우선 · Markdown 본문 변환 기준

확정일: 2026-10-07

이 보완 기준은 모든 공개·비공개 아카이브에 적용한다. 이전 문서의 "MD로 HTML을 생성하지 않는다"는 표현은 **사용 가능한 원본 HTML이 있는 경우에만** 적용한다. HTML이 없는데 MD가 있는 기록을 파일목록만으로 표시하지 않는다.

| 입력 상태 | 본문 표시 기준 |
| --- | --- |
| 원본 HTML 있음 | 기존 HTML을 우선 사용하고 내용·레이아웃·상대경로를 보존한다. MD로 기존 HTML을 덮어쓰지 않는다. |
| 원본 HTML 없음, MD 있음 | MD 전체 본문을 HTML로 렌더링하여 같은 기록의 index.html에 표시한다. MD 다운로드 링크나 첨부목록만으로 대체하지 않는다. |
| HTML·MD 모두 없음 | 확보된 TXT·미디어·문서로 가능한 자료목록과 미리보기를 제공하고, 본문 원자료 부재를 명시한다. 내용을 만들어내지 않는다. |

## 원문과 첨부 보존

- 제목·문단·표·목록·인용·코드블록·링크·이미지 등 Markdown 구조를 보존한다. 요약·금액 변경·계약 문구 수정·날짜 추정으로 대체하지 않는다.
- 원본 MD는 바이트 그대로 보존하고 원본 다운로드를 제공한다.
- 여러 MD가 있으면 대표 본문을 정하고 나머지도 HTML 보기와 원본 링크로 연결한다. 기존 원본 HTML을 변경하지 않는다.
- 이미지·PDF·DOCX·영상·음성·기존 ZIP 등 실제 첨부파일을 빠뜨리지 않고 연결한다. 파일 개수는 실제 파일에서 계산한다.
- 상대경로·공백·한글 경로를 확인한다. 원본 링크는 공개 범위를 변경하지 않는다.
- 생성 HTML은 정제된 Markdown으로 만들고 script, 이벤트 속성, javascript URL을 실행하지 않는다.

## 재생성·중복 방지

- 원본 HTML과 MD로 생성한 HTML을 구분한다. 파일목록 전용 임시 index.html은 원본 HTML로 보지 않는다.
- manifest에 entryType=markdown-generated, entrySource, sourceSha256, entrySha256, rendererVersion을 기록한다.
- MD 수정 시 기존 기록 경로의 생성 HTML을 다시 만든다. 생성된 HTML을 원본 HTML로 오인하여 재생성을 건너뛰지 않는다.
- 같은 기록에 slug를 새로 부여하거나 기록을 중복 생성하지 않는다.
- 목록·상세페이지·프로젝트 홈은 같은 canonical title을 사용한다. 변환 날짜를 사건 날짜로 바꾸지 않는다.

## 공개·비공개 및 완료 기준

- HTML 변환은 공개 범위를 바꾸지 않는다. 비공개 MD·생성 HTML·첨부는 Private GitHub에만 원본으로 보존하고 Vercel 인증 후 GitHub live-read로 제공한다.
- 중앙 공개 기준 문서에는 규칙과 일반적인 구현 정보만 기록하며 계약 당사자·주소·금액·원문은 복사하지 않는다.
- GitHub 파일 생성/커밋/CI 성공만으로 완료하지 않는다. 운영 상세에서 실제 본문, 표·인용·링크, 원본 다운로드, 인증을 확인한다.
- 기존 파일목록 전용 페이지도 원본 MD가 있으면 이 기준에 맞게 보완한다. 원본 입력은 검증 완료 전 삭제하지 않는다.

## 공통 구현

`.github/workflows/archive-markdown-fallback-reusable.yml`은 이미 존재하는 archive/ 기록의 원본 HTML을 보존하면서 MD-only 또는 기존 Markdown 생성본을 갱신한다. 각 프로젝트는 main의 MD 변경과 수동 실행에 연결하며 검증된 커밋 SHA로 고정한다.
