# 아카이브 배포 — 기준 변경 이력

## 2026-10-07 · 정리 MD/HTML/ZIP 명령의 요구사항 통합

사용자 요청: `정리 md, html to zip` 실행 시 요구하고 기억하도록 한 내용을 모두 정리하여 프롬프트로 작성하고 기준 소스에 첨부한다.

### 반영 문서

- [통합 실행 프롬프트](MD-HTML-ZIP-PROMPT.md): 23개 절(0~22), 원본 확인부터 완료 보고·중앙 기준 갱신까지.
- [요구사항 대조표](MD-HTML-ZIP-REQUIREMENTS.md): 50개 요구사항과 각 절·검증 기준 연결.
- [README](README.md) 및 [기존 통합 프롬프트 진입점](archive_deployment_prompt.md): 최신 문서와 적용 우선순위 연결.

### 명확히 한 사항

| 구분 | 통합 기준 |
|---|---|
| 정리 범위 | 현재 채팅 전체가 기본. 사용자가 지정한 일부 범위나 파일만 생성 조건이 우선 |
| 원본 | 모든 이미지·영상·음성·녹취·PDF·문서·연관 파일의 실제 원본 보존 |
| 파일명 | YYYYMMDD_내용, 사건 날짜 우선 |
| HTML | 정상 HTML 우선, 없는 경우 MD/TXT/미디어/문서에서 생성, 덤프형 HTML은 원본 보존 후 정규화 |
| 공개 범위 | 기존 범위 유지, 미지정·민감 자료 비공개 기본, 기준 소스에 개인 원문 금지 |
| 비공개 서비스 | Private GitHub 단일 원본, Vercel 인증 live-read gateway, 원본 정적 중복 배포 금지 |
| 완료 | 파일 생성·Git 반영·운영 배포·아카이브 완료 구분, 미확보·미검증 표시 |
| 입력 삭제 | 최종 운영·미디어·홈·인증 검증을 통과한 입력만 별도 cleanup |
| 소스와 기억 | 중앙 문서·필요한 구현·변경 이력·기억 갱신 결과를 구분 |

### 보존 및 범위

변경 전 README 전체는 [OPERATIONS-POLICY.md](OPERATIONS-POLICY.md), 기존 통합 프롬프트 전체는 [BASE-DEPLOYMENT-PROMPT.md](BASE-DEPLOYMENT-PROMPT.md), 이전 변경 이력 전체는 [CHANGELOG-through-20261007.md](CHANGELOG-through-20261007.md)로 원래 Git blob 그대로 보존한다. 기존 ZIP Workflow 및 HTML 보완 기준도 삭제하지 않는다.

이번 변경은 문서·기준 통합이며 개별 프로젝트의 구현·재배포·검증 완료를 주장하지 않는다. 문서에 정의한 세부 파일명·필드는 과거 사용자 요구를 실행 가능하게 구체화한 형식이며, 모두 과거의 직접 인용이라는 뜻은 아니다.

## 이전 변경 이력

2026-10-05~07의 중앙 반영 의무, HTML 우선, 세 목록 동기화, 중앙 홈 누락 방지, 비공개 gateway/Shared Token, MD 본문 표시 변경은 [이전 이력 전체](CHANGELOG-through-20261007.md)에 보존한다.
