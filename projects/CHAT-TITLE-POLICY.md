# 채팅 목록 작성일·제목 규칙

적용: 모든 공개 프로젝트 홈의 공개·비공개 채팅 목록.

표시 형식은 **YYYY-MM-DD 채팅 이름**이다. 날짜는 해당 채팅을 작성한 날짜이며, 배포일·재배포일·파일 수정일·Git 커밋일·사진 촬영일·사건 발생일을 대신 사용하지 않는다.

사용자가 직접 제목을 부여한 경우 `userTitle`을 최우선으로 사용한다. 지정 제목이 없으면 원래 채팅 제목(`chatTitle`, `originalChatTitle`), 기존 제목 순으로 사용한다. 자동 생성한 요약 제목이 사용자 지정 제목을 덮어쓰지 않는다.

## 등록과 우선순위

- 원래 채팅 작성일: `chatCreatedAt`.
- 사용자가 명시적으로 정정한 작성일: `authoredAt`을 우선 사용한다.
- 직접 부여한 제목: `userTitle`. 원래 채팅 제목: `chatTitle`.
- 작성일은 `YYYY-MM-DD` 또는 시간대가 포함된 ISO 시각으로 기록한다. 시각은 한국 시간(Asia/Seoul)의 날짜로 표시한다.
- `date`/`createdAt`처럼 뜻이 불명확한 필드는 작성일임을 명시한 `dateSource` 또는 `dateType: authored`가 있을 때만 사용한다.
- 작성일을 확인할 근거가 없으면 **작성일 미확인 채팅 이름**으로 표시한다. URL·파일명·제목 속 숫자로 작성일을 추정하지 않는다.
- 사용자 제목 앞에 작성일과 같은 날짜가 이미 있으면 표시 시에만 중복 접두 날짜를 한 번으로 정리한다. 다른 날짜가 들어 있는 사용자 제목은 그대로 유지한다.
- 날짜나 제목 변경은 기존 채팅 URL, 본문, 사진·영상·음성, 인증 방식과 원본 자료를 변경하지 않는다.

`chat-metadata.json`은 공개 허용된 작성일·제목 정보만 보관한다. `entries`의 키는 채팅의 기존 HTTPS 주소이며 끝 슬래시와 `index.html`은 같은 채팅으로 정규화한다. 쿼리 문자열은 유지하여 서로 다른 채팅을 구분한다.

원본 메타데이터를 변경하지 않고 조회 시 결합한다. 항목 자체의 명시적 작성일·제목과 프로젝트의 `chatMetadata` 정정값을 반영할 수 있다. 새 제목을 부여해도 작성일은 바뀌지 않는다.

동적 목록과 정적 홈 생성은 같은 `project-home.js`의 날짜·제목 함수를 사용한다. 기존 생성기는 `home-generator-core.py`로 그대로 보존하며, `home-generator.py`가 목록 제목만 결합한다.
