# 밥상맥박 · Food Pulse Korea

2026 KAMIS 활용사례 공모전 MVP.

## 핵심
KAMIS 가격 데이터를 단순 조회하지 않고 PRICE · PLANET · PEOPLE · HEALTH 4축으로 해석한다.

- 오늘의 품목 가격 신호
- 5만원 스마트 장바구니
- 대체 식재료 추천
- 생산자 몫 / 유통비용
- 유통 탄소부담 Proxy
- 기후플레이션 레이더
- 공급망 시각화
- 데이터 출처와 산식 공개

## 실데이터 확장
- KAMIS dailySalesList
- KAMIS periodWholesaleProductList
- KAMIS periodEcoPriceList
- 주요 농산물 유통비용율
- 공영도매시장 거래실적
- APC / 온라인도매 / 공공급식

## ESG 원칙
공인 배출계수 연결 전에는 절대 kgCO2e가 아닌 상대적 탄소부담 Proxy만 제공한다.
