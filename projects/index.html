기존 상세 정리를 축약하거나 대체하지 않습니다. 공개 정보는 해당 프로젝트의 공개 저장소에, 비공개 상세 원문은 해당 Private GitHub 저장소에 누적 보존합니다. 이 페이지는 상세 HTML·MD·사진·영상·음성·PDF·ZIP으로 연결하는 중앙 목차입니다.

비공개 원본은 해당 Private GitHub 저장소에 보관합니다. 운영 페이지의 프로젝트 자체 비밀번호 인증과 Vercel Deployment Protection 계정 인증은 서로 다른 보호 계층으로 구분해 표시합니다. 공개 HTML이나 브라우저 코드에 비밀번호·토큰·민감 원문을 넣지 않습니다.

사진·미디어는 파일명 목록만으로 포함됐다고 판단하지 않습니다. 실제 파일, 문서 연결, 직접 주소의 인증, 표시·재생 여부를 확인합니다.
