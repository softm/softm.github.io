# AdMob 광고 계정 공통 규칙

## 지배 규칙

- Google AdMob 광고를 새로 구현하거나 기존 구현을 수정할 때는 `autorunnavi@gmail.com` 계정을 사용한다.
- AdMob 앱, 광고 단위, 광고 ID를 생성하거나 코드에 반영하기 전에 현재 로그인한 Google 계정이 `autorunnavi@gmail.com`인지 확인한다.
- 다른 Google 계정의 AdMob 앱 ID 또는 광고 단위 ID를 사용하지 않는다. 예외는 사용자가 해당 작업에서 다른 계정을 명시적으로 지정한 경우뿐이다.
- 계정 이메일은 계정 식별 기준이며 비밀번호, 복구 정보, 인증 토큰 등 비밀정보는 이 저장소나 프로젝트 코드에 기록하지 않는다.

## 구현 시 함께 적용할 기준

- 광고 앱 ID와 광고 단위 ID는 앱과 지면별로 각각 발급하며 다른 앱이나 지면에서 재사용하지 않는다.
- 개발 및 검증 중에는 Google이 제공하는 테스트 광고 ID 또는 테스트 기기 설정을 사용하고, 실제 광고 클릭으로 시험하지 않는다.
- Android 네이티브 광고의 UI, 동의 흐름, 수명주기 및 테스트 방식은 루트의 [`ADMOB-NATIVE-COMMON-STANDARD.md`](../ADMOB-NATIVE-COMMON-STANDARD.md)를 함께 따른다.

## 적용 범위

이 문서는 `softm.github.io`를 루트 공통 규칙 저장소로 사용하는 모든 프로젝트의 AdMob 신규 적용 및 수정 작업에 기본적으로 적용한다. 사용자의 현재 작업 지시가 이 문서보다 우선한다.
