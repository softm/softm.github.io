계정은 함께 쓰고, 기록은 사이트마다 따로 보관합니다.
보관소의 내용은 암호화해 저장합니다.

공통 계정

연결 상태를 확인하고 있어요.

로그인은 신원 확인에만 사용합니다. SNS 게시글·사진 수집은 별도의 연결과 동의가 필요합니다.

사이트 연결

선택한 사이트의 보관소에만 접근합니다. 다른 사이트의 기록은 공유되지 않습니다.

로그인 수단 연결

로그인된 계정에 다른 SNS를 연결하면 다음부터 같은 계정으로 돌아올 수 있어요.

이미 다른 계정에 연결된 로그인은 자동으로 합치지 않습니다.

사이트별 나의 보관소

공통 모듈을 사용할 사이트 목록입니다. ‘연결 준비’는 해당 사이트의 실제 데이터 연동이 완료됐다는 뜻이 아닙니다.

나의 보관소

선택한 사이트의 개인 메모를 암호화해 보관할 수 있어요.

목록의 항목을 누르면 복호화합니다. 수정 저장은 마지막으로 읽은 버전을 확인하며, 다른 기기의 변경을 덮어쓰지 않습니다.

개인 기록의 소유자는 나입니다. 계정 로그인과 보관소 암호는 별개입니다.
