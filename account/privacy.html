공통 계정·사이트별 보관소 개인정보 안내

적용일: 2026년 10월 28일

선택해서 사용하는 계정과 보관소

Google·카카오·네이버 로그인은 사용자 신원 확인과 계정 연결에 사용합니다. SNS 게시글·사진을 자동 수집하지 않습니다. 네이버는 공개 검수 전 등록된 개발회원만 이용할 수 있습니다.

저장하는 정보

Firebase Authentication의 계정 식별자와 명시적으로 연결한 로그인 수단, 사이트 연결 정보, 저장 버전·시각과 암호화된 사이트별 기록을 Google Firebase의 한국 서울 리전 Firestore에 보관합니다. 사이트마다 저장 범위를 보관소 화면에 표시하며 다른 사이트의 기록은 합치지 않습니다. 보관소를 사용하지 않으면 기존 기기 저장 기능을 계속 사용할 수 있습니다.

암호화와 전송

사용자가 저장을 누르거나 현재 창의 자동 저장을 켠 범위만 전송합니다. 기록은 기기에서 PBKDF2·AES-GCM으로 암호화합니다. 보관소 암호와 평문 기록은 서버로 보내지 않습니다. 암호는 현재 창의 메모리에서만 사용하고 잠그기·로그아웃·페이지 종료 시 지웁니다. 로그인 계정의 복구가 보관소 암호 복구를 뜻하지 않습니다.

보관·삭제와 기존 계정

공통 사이트 보관소는 최근 5개 저장본을 유지합니다. 보관소의 원격 저장본 삭제로 해당 모듈의 저장 연결과 연결된 백업 삭제를 요청할 수 있으며, 실패하면 완료하지 못한 상태를 표시합니다. 로그아웃은 기록 삭제가 아닙니다. 별도 서비스의 기존 계정·기기 기록은 자동 이전·병합·삭제하지 않습니다. 계정 전체와 하위 자료 삭제 문의는 운영자에게 요청해 주세요.

여러 GitHub Pages 경로는 같은 웹 출처를 사용합니다. 계정 권한과 암호화 문맥으로 사이트를 구분하며 브라우저 출처 자체가 사이트마다 분리되는 것은 아닙니다.
