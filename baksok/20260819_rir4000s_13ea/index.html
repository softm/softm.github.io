5. 판매자 문의문구

안녕하세요. 린나이 RIR-4000S LNG 도시가스용 13대 구매 문의드립니다. 기존 매장 테이블에 설치된 제품은 RIR-4000 / RIR-4000N 도시가스용이며, 동일 규격 교체용으로 구매하려고 합니다. 기존 명판 기준으로 RIR-4000N은 도시가스용, 4.65kW, 2009년 04월 제조 제품입니다. 확인 부탁드릴 사항은 다음과 같습니다. 1. RIR-4000S LNG 도시가스용 13대 재고가 있는지 2. 기존 RIR-4000 / RIR-4000N과 RIR-4000S가 교체 호환되는지 3. 기존 테이블 타공에 추가 가공 없이 설치 가능한지 4. 13대 구매 시 배송비 포함 총액 5. 정품 새상품 및 A/S 가능 여부 확인 후 13대 일괄 구매 견적 부탁드립니다.
