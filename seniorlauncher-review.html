어르신 바로가기 — 권한 사용 시연

패키지: softm.android.seniorlauncher · Android 14 에뮬레이터 실제 화면 녹화 · 2026-10-19

접근성: 초점 후 자동 선택

손 조작이 어려운 사용자가 접근성 초점이 놓인 앱 바로가기를 별도 클릭 없이 실행하는 기능입니다. 초점이 유지되면 앱 내부 바로가기 버튼만 선택하며, 다른 앱 화면을 자동 조작하지 않습니다.

영상에서 ‘누르기 도움 켜짐’ 상태와 전화 버튼의 초점 표시, 전화 앱 실행을 확인할 수 있습니다. 에뮬레이터 시연용 별도 테스트 APK가 접근성 초점만 전달했습니다. 버튼 클릭은 테스트 APK가 아닌 실제 앱 접근성 서비스가 수행했습니다. 실제 통화는 하지 않았습니다.

Accessibility demonstration: a separate emulator test helper supplies accessibility focus only, without clicking. The app's real dwell accessibility service activates the focused phone shortcut. No phone call is placed.

포그라운드 서비스: 화면 위 바로가기

사용자가 직접 켠 핸들을 다른 앱 사용 중에도 유지합니다. 전화 앱 위에서 핸들로 목록을 열고, 창 상단을 끌어 위치를 옮긴 뒤 전화 바로가기를 선택하는 실제 시연입니다. 이 동작은 지속 실행되는 화면 위 바로가기 서비스로 제공됩니다.

Foreground service demonstration: the persistent handle opens shortcuts over another app. The user drags the overlay and launches a shortcut. The service is explicitly started by the user and can be stopped from the app or its ongoing notification.
