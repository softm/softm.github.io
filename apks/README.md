# Android 테스트 배포

공유 주소: https://softm.github.io/apks/

앞으로 앱 테스트 APK는 이 페이지에 추가합니다. softm.net 테스트 링크 페이지는 수정하지 않습니다.

- APK는 `apks/<앱 식별자>/<앱>-<versionCode>-release.apk`에 보관합니다. 게시한 파일은 덮어쓰지 않습니다.
- `releases.json`의 `apps`에 앱 이름, 설명, 패키지와 버전 목록을 등록합니다. 버전은 최신순입니다.
- 등록 전 실제 APK의 패키지, 버전, 최소 Android, 배포 서명 및 SHA-256을 확인합니다.
- 표시 형식은 `버전: versionName (versionCode) - label`입니다. label은 앱별 식별자를 정확히 지정합니다.
- 앱 검색과 이전 버전 목록은 데이터에 따라 자동으로 표시됩니다.
- APK 공개 업로드를 명시적으로 요청받은 경우에만 해당 파일을 커밋·게시합니다. 키스토어와 인증정보는 포함하지 않습니다.
- 배포 후 페이지와 APK 다운로드를 확인하고 원본과 다운로드 파일의 SHA-256을 비교합니다.
